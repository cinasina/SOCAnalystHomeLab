# First SIEM Lab — Wazuh

This module was my first hands-on experience deploying a SIEM platform.

## What I Learned

- The basic purpose of a SIEM.
- The role of the Wazuh Server, Indexer, and Dashboard.
- How a SIEM environment is structured at a basic level.
- How to bring up a Wazuh lab and access its dashboard.

## Lab

I deployed Wazuh on an Ubuntu Server virtual machine and explored the dashboard and main platform components.

This gave me a basic understanding of how a SIEM environment is deployed before connecting real endpoints in the next module.
