# Windows & Linux Endpoint Onboarding

This module focused on understanding how endpoints connect to a SIEM through agents.

## What I Learned

- What a SIEM agent is.
- Why an agent is installed on an endpoint.
- How an endpoint connects to a Wazuh manager.
- How to install Wazuh agents on Windows and Linux.
- How to check endpoint registration and connection status.

## Lab

I installed Wazuh agents on Windows 11 and Ubuntu and connected both endpoints to my Wazuh lab.

Because of limited VM resources, I tested the Windows and Linux endpoints separately instead of keeping all virtual machines running at the same time.
