# Investigating the Unknown

This module focused on how to investigate unfamiliar processes, files, and activity without immediately assuming they are malicious.

## What I Learned

When investigating unknown activity, useful pivots include:

- Process name
- File path
- Parent process
- Command line
- User and host
- Digital signature
- File hash
- Network activity
- Related activity before and after the event

I also practiced separating confirmed facts from investigation hypotheses.

The main lesson was to investigate unknown activity systematically instead of relying only on names, severity, or first impressions.
