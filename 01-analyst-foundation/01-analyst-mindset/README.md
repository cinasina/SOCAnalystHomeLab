# SOC Analyst Mindset

This module focused on the basic investigation mindset of a SOC analyst.

## What I Learned

- An alert is not automatically an incident.
- Separate confirmed facts from assumptions.
- Understand context before making a decision.
- Look for related evidence before reaching a conclusion.
- Consider the scope of the observed activity.
- Use clear investigation outcomes such as benign, suspicious, malicious, or inconclusive.
- Document findings clearly when escalation is needed.

## Investigation Model

Context → Evidence → Correlation → Verdict → Communication
